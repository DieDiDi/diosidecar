# Security policy

Security reports against the latest DioSidecar release are welcome. Please report an issue privately through **Security → Report a vulnerability** and include the affected version, operating system, impact and steps to reproduce.

Use a sample diagram when possible. Remove credentials, private diagram content and chat history before attaching logs or screenshots.

- [Report a DioSidecar vulnerability privately](https://github.com/DieDiDi/diosidecar/security/advisories/new)
- [Report issues in the upstream draw.io editor](https://github.com/jgraph/drawio/security/advisories/new)
